# Livraria LivraLendo

Projeto de website de uma livraria fictícia. O sistema é uma aplicação funcional construída com HTML5, CSS3 e JavaScript puro.

## 🛠️ Tecnologias Utilizadas e Justificativa

- **HTML5 Semântico:** Utilizado para estruturar a aplicação com tags nativas (`<header>`, `<nav>`, `<main>`, `<section>`, `<article>`, `<footer>`), garantindo boa acessibilidade e SEO.
- **CSS3 Puro (Flexbox & Grid):** Adotado para construir um layout 100% responsivo com variáveis CSS para padronização de cores e tipografia, sem necessidade de frameworks externos.
- **JavaScript Nativo:** Escolhido para gerenciar a manipulação dinâmica do DOM, regras de negócio do carrinho, filtros em tempo real, validações e persistência de estado.

---

## 🚀 Funcionalidades Implementadas

### Requisitos Obrigatórios:

1. **Home (Página Inicial):** Banner promocional de destaque, vitrine com 4 livros principais, cabeçalho e rodapé padronizados.
2. **Catálogo Completo:** Exibição de 12 livros divididos em 4 categorias (Romance, Fantasia, Técnicos e Infantil).
3. **Detalhes do Livro:** Visualização em modal contendo sinopse, capa ampliada, autor, editora, ano, número de páginas e preço.
4. **Busca e Filtro por Categoria:** Filtro instantâneo por entrada de texto (título/autor) e botões por gênero literário.
5. **Carrinho de Compras Funcional:** Adição de itens, alteração de quantidade, remoção, cálculo automático do subtotal/total e contador dinâmico de itens no menu.
6. **Finalização de Compra:** Formatação e validação de entrega para fechar pedidos na página do carrinho.
7. **Validação de Formulário:** Formulário de contato com checagem de formato de e-mail e exibição de feedback direto na tela.
8. **Persistência de Dados:** Uso de `localStorage` para manter os itens do carrinho salvos após recarregar ou navegar entre páginas.

### Extras Implementados (Bônus):

- 🌙 **Modo Claro / Escuro:** Alternância de tema com salvamento de preferência no `localStorage`.
- ⭐ **Avaliação por Estrelas:** Sistema visual de classificação por estrelas na exibição dos detalhes do livro.
